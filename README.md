# Лендинг семейного юриста Елены Соколовой

Одностраничный адаптивный лендинг для практикующего юриста по семейному праву.
Свёрстан вручную без UI-фреймворков: чистый HTML5, CSS3 и vanilla JavaScript.

## 🔗 Демо

- **Живой сайт:** https://lawyer.riool-hw.ru

## Возможности

- Адаптивная вёрстка (mobile-first), корректно работает от 320 до 1440+ px.
- Липкая шапка с навигацией по якорям и мобильным бургер-меню.
- 6 смысловых блоков: Hero, Услуги и цены, Этапы работы, Отзывы, FAQ, Форма заявки.
- Блок «Услуги» показывается таблицей на десктопе и карточками на мобильных.
- Аккордеон FAQ с плавным раскрытием ответов.
- CTA-кнопка с плавной прокруткой к форме.
- Встроенная Яндекс Форма для приёма заявок.
- Доступность: ARIA-атрибуты, семантическая разметка, фокус-стили.
- Собственная SVG-favicon (весы правосудия) в фирменной палитре.

## Технологии

- **HTML5** — семантическая разметка.
- **CSS3** — CSS-переменные, Flexbox, Grid, медиа-запросы (mobile-first).
- **JavaScript (ES6)** — аккордеон, плавный скролл, бургер-меню.
- **Яндекс Формы** — приём заявок через встроенный iframe.
- **Google Fonts** — Montserrat и Open Sans.

## Дизайн-система

| Переменная          | Цвет      | Назначение                       |
| ------------------- | --------- | -------------------------------- |
| `--color-primary`   | `#1B3A5C` | Navy — заголовки, футер, акценты |
| `--color-bg-light`  | `#F4F1EA` | Warm Sand — фоны блоков, карточки |
| `--color-secondary` | `#5D7692` | Slate Blue — подзаголовки, границы |
| `--color-white`     | `#FFFFFF` | Белый — фон формы, текст на тёмном |
| `--color-accent`    | `#C8A97E` | Muted Gold — CTA-кнопки, цифры   |

Базовые параметры: шрифт 16px / 1.6, скругление 12px,
тень `0 4px 20px rgba(27, 58, 92, 0.08)`,
breakpoints 320 / 768 / 1024 / 1440 px.

## Запуск локально

Просто откройте `index.html` в браузере. Для корректной работы встроенной
Яндекс Формы рекомендуется поднять локальный сервер (форма блокируется на `file://`):

```bash
# Python 3
python -m http.server 8000

# или Node.js
npx serve
```

Затем откройте http://localhost:8000.
